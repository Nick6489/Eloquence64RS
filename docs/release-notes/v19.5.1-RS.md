# Eloquence64RS 19.5.1-RS

This release moves sound-contour processing into the independent
[Eloquence contours module](https://github.com/Nick6489/eloquence-contours),
loaded as a DLL by the add-on. The Rust host supplies raw engine audio.

Existing EQ curves, gains, sample rates, contour selections, profile settings,
and keyboard commands remain unchanged. No configuration migration is needed.

## New: Presence treble

Choose **11.025 kHz**, then select **Presence treble** under **Sound contour**.
This new option faithfully reproduces the audio processing from hozosch's
Eloquence v19.1 resampler, including its interpolation, adaptive smoothing,
presence shaping, notches, gain and dither. Its broad upper-presence lift
peaks near 4.2 kHz. Existing Raw, Presence and Smooth processing is unchanged.

The port was checked sample for sample against the original release DLL.
Its implementation, tests and measured response live in the separate
[contours repository](https://github.com/Nick6489/eloquence-contours).

## Installation

The package includes contour DLLs for both NVDA architectures and an updated 32-bit engine host.
Install the package and restart NVDA as usual. Secure-screen installations
must receive the updated host using the existing Copy Helper action.

If Windows blocks an update, close File Explorer windows displaying the
installed Eloquence folder and restart NVDA to complete the pending update.

## Building from source

Run `build_contours.cmd` to build the pinned revision of the independent
module and copy its DLL, adapter, and license into the add-on. Then run
`build_host.cmd`. Both builds use the existing Rust/MSVC toolchain.

For the stable package, set `ELOQUENCE_BUILD_VERSION=19.5.1-RS` and run
`python -m SCons` using system-installed 64-bit Python. This produces
`Eloquence-19.5.1-RS.nvda-addon`. Publishing the release and updating the
stable updater feed are separate from building the package.
