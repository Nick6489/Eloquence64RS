# Eloquence64RS 19.5-RS

Eloquence64RS 19.5 adds native 16 kHz synthesis and selectable sound contours,
with reliability fixes for startup and synthesizer switching.

## Audio and settings

- Choose 11.025 kHz or native 16 kHz synthesis independently of the sound contour.
- Choose Raw or Presence at 11.025 kHz, and Raw, Presence, or Smooth at 16 kHz.
- Save a separate contour selection for each sample rate in each NVDA configuration profile.
- Migrate the former Enhanced setting to Presence at 11.025 kHz. Existing
  contour-checkbox selections are migrated automatically.
- Load native voice data faster by patching private temporary files in memory
  before writing them once. Installed voice data remains unchanged.
- Use Alt+Q for the Sample rate setting.

## Reliability

- Fix persistent silence after switching away from Eloquence and back while
  it is speaking, including configuration-profile switches. Changing audio
  settings during speech could cause the same failure. Each replacement audio
  worker now receives a fresh queue, isolating leftover stop markers and audio.
- Restore saved sound contours at NVDA startup without accessing the GUI before
  it exists.
- Deliver speech-progress notifications with real audio chunks rather than
  zero-byte playback markers.
- Place native hosts in a Windows Job Object when available so they cannot
  survive an unexpected NVDA exit, and redact host authentication keys from logs.
- Report pronunciation dictionary entries added, changed, or removed, and
  identify downloads that are already up to date.

## Installation and release status

This stable-version package is prepared for final installation testing and has
not yet been published. The prepared updater metadata is local to the development
branch; installed users receive it only after promotion to the `stable` branch.

Remove or disable IBMTTS before installing. Eloquence64RS replaces Eloquence64
and should not be installed alongside another Eloquence add-on.

After installing, restart NVDA. If you use Eloquence on secure screens, copy
the updated helper again using **NVDA Settings > Eloquence > Copy Helper to
System Config (for Logon Screen)**.
