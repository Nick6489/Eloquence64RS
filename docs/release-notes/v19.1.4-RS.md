# Eloquence64RS 19.1.4-RS

Eloquence64RS 19.1.4 is an urgent stable hotfix for clean shutdown of the
32-bit Eloquence host when NVDA exits or switches synthesizers.

## Fixes

- Shuts down the native Eloquence host when NVDA terminates the synthesizer.
- Gives the host up to three seconds to exit cleanly before forcing it to stop.
- Prevents PyInstaller `_MEI` temporary directories from accumulating after
  NVDA restarts.
- Prevents shutdown-time connection errors from interrupting a synthesizer
  switch.
- Keeps forced process termination as a fallback if the host does not exit on
  its own.

## Installation

Remove or disable the IBMTTS add-on before installing. Eloquence64RS replaces
Eloquence64 and should not be installed alongside another Eloquence add-on.

The built-in updater follows only the production metadata maintained on the
repository's `stable` branch. Publishing this release promotes that metadata
from 19.1.3-RS to 19.1.4-RS.
