# Eloquence64RS 19.5 Beta 1

This beta separates Eloquence's synthesis rate from its optional Presence
processing so listeners can choose the combination they prefer.

- Replaces Enhanced 22 kHz with two independent settings: 11.025 kHz or
  16 kHz synthesis, plus an optional Presence contour.
- Migrates every former Enhanced selection to Presence enabled at 11.025 kHz,
  including profile-specific settings. This retains the established 2x
  reconstruction and 22.05 kHz playback without opting users into 16 kHz.
- Applies validated 16 kHz patch descriptors only to private staged voice
  files. Installed Eloquence data is never patched in place.
- Restores live language, variant, prosody, dictionary, and Presence state when
  a sample-rate profile change restarts the engine.
- Applies the rate-adjusted Presence contour directly at 16 kHz without
  resampling.

Please report the selected sample rate and Presence setting when describing
audio differences or regressions.
