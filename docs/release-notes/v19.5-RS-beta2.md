# Eloquence64RS 19.5 Beta 2

This beta retunes the Presence contour using end-to-end recordings from the
11.025 kHz and native 16 kHz synthesis paths.

- Restores the preferred 11.025 kHz Presence sound, including its 2x
  reconstruction, with a gentle post-interpolation correction for the upper
  transition band.
- Replaces the sustained high-frequency shelf at native 16 kHz with a broad
  articulation peak centered at 4.8 kHz. This follows the tonal envelope of
  the preferred earlier reconstruction while reducing lispiness.
- Preserves genuine native bandwidth above the articulation region instead of
  reproducing the earlier reconstruction's aliasing and steep high-frequency
  roll-off.
- Adds a test-only PCM capture path for repeatable native-host audio analysis.

The sample-rate and Presence controls, including migration from the former
Enhanced setting, are unchanged from Beta 1.
