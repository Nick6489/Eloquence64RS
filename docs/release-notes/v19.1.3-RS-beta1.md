# Eloquence64RS 19.1.3-RS Beta

Eloquence64RS 19.1.3-RS Beta stops a cancelled Speech Sequence from starting a
new Speech Generation after Stop.

Cancel during the blocking voice-parameter reset at the start of an utterance
could still send leftover text and synthesize commands. The protocol client
then treated that leftover addText as a new utterance. The synth worker now
re-checks the Speech Generation before each command, and the Host Channel does
not open a generation after Stop unless the next utterance explicitly prepares
one.

This beta is for audible testing of cancellation and the following utterance.
The production updater remains pinned to the stable branch and does not offer
this beta automatically.
