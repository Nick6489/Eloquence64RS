# Eloquence64RS 19.1.3-RS

Eloquence64RS 19.1.3 is a stable hotfix so a cancelled Speech Sequence cannot
start a new Speech Generation after Stop.

## Fixes

- Re-checks the Speech Generation before each synth-worker command, so cancel
  during the blocking voice-parameter reset no longer sends leftover text,
  indexes, or synthesize commands.
- Stops the Host Channel from opening a new generation after Stop unless the
  next utterance explicitly prepares one. Leftover addText from a cancelled
  item can no longer become a new utterance.
- Still starts the following utterance normally after cancel.

## Installation

Remove or disable the IBMTTS add-on before installing. Eloquence64RS replaces
Eloquence64 and should not be installed alongside another Eloquence add-on.

The built-in updater follows only the production metadata maintained on the
repository's `stable` branch. Publishing this release promotes that metadata
from 19.1.2-RS to 19.1.3-RS.
