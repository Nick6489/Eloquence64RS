# Eloquence64RS 19.1-RS

Eloquence64RS 19.1 is the stable release of the enhanced-audio and dictionary
profile work tested throughout the 19.1 beta series. Standard 11 kHz output
remains the default, and Eloquence's built-in pronunciation behavior remains
available without a custom dictionary.

## Highlights

- Adds an optional **Enhanced 22 kHz** mode with stateful 2x interpolation,
  suppression of mirrored high-frequency energy, gentle high-frequency
  emphasis, and a subtle vocal-body lift.
- Keeps **Standard 11 kHz** output bit-exact and selected by default.
- Restores the selected audio mode correctly after changing away from and back
  to Eloquence.
- Replaces the old shared dictionary updater with isolated pronunciation
  profiles for Eloquence's built-in behavior, alternative dictionaries,
  community dictionaries, and retained custom dictionaries.
- Allows users to switch back to Eloquence's built-in pronunciations at any
  time, without leaving stale custom dictionaries active.
- Downloads complete provider snapshots atomically, so updating one profile
  cannot merge it with or damage another profile.
- Activates downloaded or selected dictionary profiles immediately and updates
  their displayed download state without reopening NVDA Settings.
- Preserves existing custom dictionary files across migration and add-on
  upgrades.
- Expands Python and Rust regression coverage for audio quality, dictionary
  migration and updates, live dictionary switching, native-host protocol
  behavior, and add-on installation.

## Installation

Remove or disable the IBMTTS add-on before installing. Eloquence64RS replaces
Eloquence64 and should not be installed alongside another Eloquence add-on.

This release updates the native-host protocol. After updating, users who need
Eloquence on logon or other secure screens must open **NVDA Settings >
Eloquence** and run **Copy Helper to System Config (for Logon Screen)** again.

The built-in updater follows only the production metadata maintained on the
repository's `stable` branch. Publishing this release promotes that metadata
from 19.0-RS to 19.1-RS.
