# Eloquence64RS 19.1.1-RS

Eloquence64RS 19.1.1 is a stable hotfix for pronunciation dictionary profiles.

## Fix

- Pronunciation dictionary selection now follows NVDA configuration profile
  changes immediately. Switching profiles no longer leaves the dictionary from
  the previously active profile loaded in the Eloquence Host Process.

## Installation

Remove or disable the IBMTTS add-on before installing. Eloquence64RS replaces
Eloquence64 and should not be installed alongside another Eloquence add-on.
