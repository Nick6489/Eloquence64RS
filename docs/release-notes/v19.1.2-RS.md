# Eloquence64RS 19.1.2-RS

Eloquence64RS 19.1.2 is a stable hotfix for NVDA configuration-profile
isolation when profiles use different audio output devices.

## Fixes

- Keeps Eloquence voice, variant, rate, pitch, inflection, volume, voice-shape,
  dictionary, pause, and audio-quality settings isolated between NVDA
  configuration profiles when an audio-device change recreates the synthesizer.
- Preserves corrected profile settings across NVDA restarts instead of saving
  the outgoing profile's values into the incoming profile.
- Supports manually activated profiles, application-triggered profiles, and
  stacked manual and triggered profiles.
- Prevents raw boolean profile values from interrupting Eloquence speech.

## Installation

Remove or disable the IBMTTS add-on before installing. Eloquence64RS replaces
Eloquence64 and should not be installed alongside another Eloquence add-on.
