# Eloquence64RS 19.5 RC1

The first release candidate for 19.5 includes the sound contour choices and
saved-settings startup fix from Beta 5.1, plus faster native 16 kHz loading.

Native voice data is now patched in memory and written to its private temporary
files once, avoiding the extra copy and reread during initialization. The add-on
continues to carry a single installed dataset and validates every native patch.

Synthesis buffers, speech indexing, and sound contour processing remain unchanged
from Beta 5.1. Raw, Presence, and Smooth retain their existing behavior, including
separate contour selections for each sample rate and NVDA configuration profile.

Validation: 54 Rust tests passed, including real 16 kHz synthesis. The local
development package was tested successfully before promotion to RC1.
