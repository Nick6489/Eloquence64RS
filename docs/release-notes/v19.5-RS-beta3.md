# Eloquence64RS 19.5 Beta 3

This beta replaces the native 16 kHz Presence contour with the curve selected
from listening tests and strengthens cleanup of the 32-bit Eloquence host.

## Audio

- Replaces the native 16 kHz Presence profile with the two-band ReaEQ curve
  selected from raw Eloquence output.
- Reproduces the 1,219.5 Hz band directly and rate-translates the 7,565.6 Hz
  band so it retains the intended response near the 8 kHz Nyquist limit.
- Keeps the established 11.025 kHz Presence profile unchanged.
- Preserves the raw native output level outside the new cut-only EQ bands.

## Reliability and privacy

- Places each native host in a best-effort Windows Job Object so a host wedged
  inside ECI cannot survive after NVDA exits unexpectedly.
- Keeps the normal graceful host shutdown path and uses forced termination only
  as a last resort.
- Redacts the native host's ephemeral authentication key from NVDA logs.
- Updates host-channel diagnostics to describe the inherited standard-input and
  standard-output pipes accurately.

## Keyboard access

- Changes the Sample rate setting mnemonic to Alt+Q, avoiding a conflict with
  other speech-setting shortcuts.
